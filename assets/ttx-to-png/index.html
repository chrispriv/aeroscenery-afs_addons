    Disclaimer: outputs are preview decodes of GPU/audio data inside the container — not a guaranteed copy of the artist’s original file. Textures may have been flipped, scaled, mipmapped, or block-compressed; sounds are typically mono 16-bit PCM for in-game 3D placement. .toc text matches official Aerofly syntax for xref cultivation tables; shipping compress_file=true still needs IPACS tools. Re-encoding casually can look/sound wrong or crash the game. PNG → .ttx is an unofficial encoder: block formats are lossy, and the file is plain (compress_file off, no LZHAM). Prefer the IPACS converter for anything you ship.

    Textures: type_rgba, type_r, type_rg_rgtc2, DXT1/3/5, ASTC, ETC2(+EAC). Encode: ETC2, or DXT1 — DXT5 / ETC2 RGBA when the image has alpha. Sounds: mono16 → WAV. Scenery: .toc → .toc.txt / JSON (xref lists). Optional compress_file (LZHAM) on decode.
